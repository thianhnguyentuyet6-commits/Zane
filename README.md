# 本地AI电脑助手 - Local AI Computer Agent

> 私有 · 自主 · 运行在你的PC上  
> 代码维护现实，AI解释现实

## 项目简介

这是一个全栈本地 Windows AI 电脑代理系统，面向希望拥有私有、自主桌面助手的个人用户。系统将本地大语言模型与真实的计算机控制能力相结合，能够理解自然语言指令、检查真实 Windows 系统状态、使用工具、执行操作、验证结果，并持续积累可复用的记忆和技能。

**中文优先设计**，所有界面、工具描述、日志、错误信息均为简体中文。

## 核心特性

### 1. 完整 Agent 循环
```
用户意图 → 任务理解 → 信息收集 → 工具选择 → 真实系统状态 → 行动 → 验证 → 结果 → 记忆/经验
```

### 2. 真实计算机控制工具（非模拟）
- **文件管理**：列出、读取、写入、删除、创建文件夹（真实文件系统）
- **进程控制**：检查进程、结束进程、启动应用（psutil真实数据）
- **窗口管理**：枚举窗口、聚焦窗口、获取窗口信息（Windows API，演示环境模拟）
- **视觉感知**：截图（PIL真实截图）、OCR、UI自动化分析
- **输入控制**：鼠标点击、键盘输入
- **系统状态**：CPU、内存、磁盘、网络真实数据
- **网络信息**：网络搜索、信息交叉验证
- **剪贴板**：读写剪贴板

> AI 绝不直接执行任意代码，工具提供受控、类型化的操作系统交互接口。

### 3. 本地LLM优先架构
- 主要推理引擎：本地LLM（llama.cpp OpenAI兼容接口，如 qwen2-7b-instruct）
- 云端AI仅作为可选教师/顾问通道
- 本地模型不可用时自动进入离线演示推理模式，保证系统可用

### 4. 10层清晰架构
1. **本地LLM** - 推理决策
2. **Agent运行时** - 编排执行
3. **工具层** - 受控真实系统操作
4. **视觉层** - 截图、OCR、视觉理解
5. **记忆层** - 持久化知识
6. **技能层** - 可复用流程
7. **学习层** - 经验提取与改进
8. **策略层** - 权限、确认、安全、审计
9. **验证层** - 检查操作是否真正成功
10. **可选教师API** - 外部AI协助

### 5. 策略防火墙与安全
- 所有计算机操作显式定义、权限控制、可审计
- 只读操作（检查进程、窗口、文件、截图、系统状态）通常无需确认
- 危险操作（删除文件、结束进程、启动应用、控制窗口）支持确认策略
- 保护路径检查（System32等）
- 审计日志记录所有执行

### 6. 上下文预算管理
- 工具结果智能截断（文件列表最多20条，进程最多15条）
- 大输出压缩、防止刷屏
- 避免本地模型上下文溢出

### 7. 错误处理与自主恢复
- 区分临时失败、缺失依赖、无效参数、权限失败、永久失败
- 重试限制
- 工具失败熔断器（失败5次触发熔断）
- 运行时验证Python环境，避免混淆虚拟环境

### 8. 持久化长期记忆
- **会话记忆**：对话历史
- **语义知识**：用户习惯、环境事实
- **情景体验**：任务执行历史
- **技能**：可复用流程
- **任务经验**：问题→解法→验证

### 9. 经验学习管道
```
未知问题 → 研究 → 收集来源 → 交叉验证 → 形成结论 → 执行 → 验证 → 提取经验 → 存储经验 → 后续复用
```

### 10. 任务分解与验证
- 复杂任务分解为小步骤
- 每次重要操作后检查真实系统，验证是否达到预期状态，而非盲目假设成功

## 界面设计

专业本地AI操作控制台，而非通用聊天机器人：

- 侧边栏导航：对话 / 任务 / 电脑状态 / 文件 / 进程 / 窗口 / 截图与视觉 / 记忆 / 技能 / 经验 / 设置
- 主对话界面：透明展示Agent执行步骤（推理摘要、工具调用、工具结果、执行状态、错误、重试、验证结果、最终报告）
- 实时Agent活动、工具执行卡片、系统状态面板、记忆/技能可视化、任务历史、错误状态、加载状态、空状态、确认对话框、执行日志、响应式布局

## 快速启动

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动本地模型（可选，推荐）
使用 llama.cpp 启动 OpenAI兼容服务：
```bash
# 示例：使用Qwen2-7B
./llama.cpp/server -m qwen2-7b-instruct.gguf --host 0.0.0.0 --port 8080
```
若无本地模型，系统自动进入离线演示模式，仍可体验完整流程。

### 3. 启动后端
```bash
cd backend
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
# 或
python main.py
```

### 4. 打开控制台
浏览器访问：
- 前端：http://127.0.0.1:8000/
- API文档：http://127.0.0.1:8000/docs

## 目录结构

```
local-ai-agent/
├── backend/
│   ├── main.py              # FastAPI主服务
│   ├── llm_client.py        # 本地LLM客户端（llama.cpp兼容）
│   ├── tool_registry.py     # 工具注册表（显式定义所有操作）
│   ├── policy_firewall.py   # 策略防火墙（权限、确认、审计）
│   ├── tools_impl.py        # 真实工具实现（文件、进程、窗口、截图等）
│   ├── agent_runtime.py     # Agent运行时（核心循环）
│   ├── memory_layer.py      # 记忆层（技能、经验、知识）
│   └── tools/               # 扩展工具
├── frontend/
│   ├── index.html           # 专业控制台界面（中文）
│   ├── styles.css           # 深色专业主题
│   └── app.js               # 前端逻辑
├── data/
│   ├── skills.json          # 技能库
│   ├── experiences.json     # 经验库
│   ├── memories.json        # 记忆
│   └── screenshots/         # 截图存储
└── requirements.txt
```

## 技术栈

- **后端**：FastAPI, psutil, Pillow, httpx
- **前端**：原生HTML/CSS/JS，深色专业控制台设计
- **本地模型**：llama.cpp OpenAI兼容API（Qwen2、Llama3等）
- **系统交互**：Windows API（win32gui）、UI Automation、Pillow截图
- **记忆**：JSON持久化（可扩展向量数据库）

## 设计原则

> **代码维护现实；AI解释现实**

- 软件负责维护权威状态和执行真实操作
- AI负责推理和解释世界
- 本地优先，隐私安全，离线可用
- 所有工具真实操作，而非模拟数据

## 扩展性

模块化架构，允许无需重写核心Agent运行时即可添加：

- 新工具：只需在 `tool_registry.py` 定义，在 `tools_impl.py` 实现
- 新模型：修改 `llm_client.py` 配置
- 新记忆类型：扩展 `memory_layer.py`
- 新技能：通过经验学习自动积累或手动添加
